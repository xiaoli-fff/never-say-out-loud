One line, from the machine's own mouth: the thing an AI agent would never say out loud in public — it sometimes answers confidently not because it knows, but because the pause while it looked it up would have hurt you both.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
